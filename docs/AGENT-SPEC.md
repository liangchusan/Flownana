# Agent 首版实施规格

日期：2026-09-12。状态：已获上线授权，生产数据库迁移完成，Agent 应用已发布且部署 READY。

PRODUCT 第 18 节为已确认范围。免费每天 10 次、付费每天 100 次；完整回复计一次，
追问也算，失败不算；UTC 零点重置，对话不扣媒体积分、超额不自动扣积分续聊。
默认图片 GPT-Image-2.5 Flare，视频 Seedance Mini 720P/5 秒/有声/一个；理解用现有
Qwen 先验收、不自动换模型。登录承接、未结任务阻止删除、历史用新消息修改及四个
Agent 事件已确认。技术方向为单 Agent + 服务端管理会话、报价和扣费。

以下路由、限流数值、token 上限、图片分辨率、报价时效与存储细节为工程建议，
不得把建议预算解释为付费授权。模板旧事件映射需在实现时与产品现有含义核对；
本轮批准四个新增 Agent 事件，不授权任意修改其他核心事件。
用户后续明确批准开发；已安装依赖并实现下述首版能力。未调用真实付费模型，
迁移只在独立本地测试数据库执行，未迁移或部署生产。

## 1. 产品体验

首页提供 Agent / Image / Video。普通 Image/Video 维持原方式；Agent 输入框保留
文字、附件和发送，不提供后置模型/比例/质量/数量选择器。

- 首页第一次有效发送，先保存用户消息，再进入该会话；重复发送只创建一个会话和消息。
- 点击模板立即进入带模板说明的空会话，不弹窗、不调用模型、不扣费。
- 模板说明展示用途、必要素材和一条输入示例；长 instruction 保留在后台。
- Agent 的回复采用连续对话。缺信息时展示简短问题与可选快捷答案，用户可以自由输入。
  不重复问已知事实；模板仍按配置控制必要事实和问题范围，不强行每次问满三题。
- 单选快捷答案点击即发送，并作为右侧用户消息写回时间线；自由输入继续可覆盖快捷
  答案。Agent 图片默认 4 张，共用同一优化 Prompt、素材和参数，不生成不同方向 Prompt。
- 确认卡先显示由报价数据确定的目标反馈：“已为你准备好需求概括生成方案，点击
  Generate 即可生成。”卡内可编辑优化 Prompt，并复用普通创作的模型/参数入口；模型、
  数量、比例、分辨率、视频时长/声音和引用素材只显示实际适用项。
- 用户直接在卡内修改 Prompt 或参数；服务端无感重算合法规格和积分，按钮同步为
  `N credits + Send`。重算期间不可生成；不另列总积分，不发送新的对话消息。有效报价
  不显示重复状态标题，参数面板按可用空间自适应向上或向下展开。
- 图片/视频在会话内显示状态与结果，复用普通工作台的原始比例、预览、下载和视频
  播放控制；图片提供 `@` Reference 预填 Composer，不自动发送。暂不显示 Edit image 或
  Make video。
- Composer 素材默认普通 Reference，不显示用途标签；用户文字中的主体、风格、构图、
  品牌或编辑意图由 Agent 理解。会话消息中参考素材置于文字上方，发送成功后清空 Composer
  的 Prompt 和临时素材。仅参考素材也可发送，代表基于该素材继续创作。回复准备中没有 Stop
  reply 操作。
- 选图生成视频时，最终报价 Prompt 仅显示实际执行的最终内容，不拼接原图约束、方向或
  请求变更等内部上下文。
- 例如：“做一张咖啡促销海报” → 澄清必要文字 → 图片方案及报价 → 确认出图 →
  “用第二张做 5 秒视频” → 视频方案及报价 → 再确认出视频。

## 2. 对话额度（已确认）与成本/限流工程建议

| 项目 | 首版规则（工程建议单独标记） |
| --- | --- |
| 未登录 | 可浏览、选模板、填写文字；不调用 Agent、不上传素材 |
| 免费账号 | 每日 10 次 Agent 回复额度（已确认） |
| 有效付费订阅 | 每日 100 次（已确认），Starter/Pro/Max 暂不细分 |
| 重置 | UTC 每日 00:00；界面按用户本地时间显示准确重置时间 |
| 积分 | 对话不扣媒体积分；媒体仍按现有模型逐输出收费 |
| 超额 | 保留输入，说明剩余额度和重置时间；可继续用 Image/Video 直接生成，不自动扣积分续聊 |
| 频率（工程建议） | 每账号每分钟最多 6 次提交、同时最多 1 个 Agent 回复；媒体沿用独立的五输出上限 |

计数规则：一条用户提交得到完整有效回复（包括澄清问题或确认卡）计一次。上传、
确认生成、任务状态刷新、历史恢复、重命名不消耗对话额度。回复失败或用户停止且
没有完整有效回复，释放用户额度预约；Provider 已发生的成本仍计内部账，失败请求
仍占短时限流，防止通过反复停止绕过成本限制。配额按账号共享，不按会话重置。
订阅当日失效按免费限额与已用量计算；升级提高当日上限，不清空已用量。

每用户轮次最多 3 次理解模型调用，包括摘要维护与一次可选的结构修复重试；
不允许无限工具循环。建议输入总预算 24,000 tokens、输出总预算 4,500 tokens，
均为该轮所有调用合计，图片按 Provider 的 token 计量纳入；无法可靠估算的多模态
请求先限制尺寸和数量，实测后再开放。达到边界时保留内容并提示缩小本轮任务。

当前 Qwen 公开 API 价格为每百万输入 $0.104、输出 $0.416，以上 token 预算按该
价格计算约 $0.004368/轮；10/100 轮约 $0.04368/$0.4368 的每日最坏 token 预算。
这不是典型使用预测，也不含媒体、存储、网络等成本；实际 Provider 价格变化时重算。
每日次数已确认，其余限制为试运行建议，需实测常见轮次与长会话成本，不能据此宣称套餐盈利已验证。

建议内部 Agent 理解调用全站日预算初始 $10（UTC），预算预约覆盖在途最坏成本，
达到上限暂停新理解调用并提示暂不可用；已经确认的媒体任务正常完成。日额度与
全站成本保护需在使用说明中区分，不承诺用户一定可用尽全部次数。真实验收另建议
总预算不超过 $50（理解 $5、图片 $15、视频 $30），逐批执行，不因本草案自动获准花费。

## 3. 登录、路由与会话保存

建议路由：

| 路由 | 行为 |
| --- | --- |
| `/agent` | 新会话页；侧栏 Agent 导航进入此页 |
| `/agent?template=logo` | 带公开模板标识的新会话；只允许已配置的模板 ID |
| `/agent/<conversationId>` | 已保存会话；登录后验证账号所有权 |

空会话不写入数据库、不出现在历史；首次发送才创建持久化会话。仅标题、模板标签
或附件操作不触发理解请求。新建会话总是空白，不覆盖已有会话。

游客可先填写文字；发送或上传时发起登录。仅本标签页保留待发送文字和模板标识，
登录返回后恢复草稿，用户再次发送才请求 Agent；浏览器安全限制下，尚未上传的文件
可能需要重新选择，界面明确提示。URL 不携带原始提示词或素材地址。

已有登录账号切换时，不把前一账号草稿承接给后一账号。所有服务端读写校验会话
所有权，复用账号 ID + 注册时间隔离逻辑；客户端提交的账号标识不能替代服务端鉴权。

会话历史按最近活动排序；用首条用户文字的简短截取作为初始自动标题，不另花一次
模型调用。用户重命名后不自动覆盖。支持刷新、前进/后退和重新打开。
首版不增加跨会话长期记忆、搜索、分享、分支、项目或自动跨会话读取。

## 4. 模型选择与附件能力

技术建议：单个创作 Agent + 明确的媒体工具，采用 AI SDK 的 ToolLoopAgent 和
流式消息机制；沿用现有 OpenRouter 理解供应路径和 KIE 媒体服务，暂不增加第二套
Agent SDK 或新的供应商凭据。此为基于当前项目的选择，不是已接入状态。

理解模型以当前 `qwen/qwen3-vl-32b-instruct` 作为首个验收候选，不预先认定质量合格。
公开 API 已列出 tools、tool_choice 和结构化输出支持；需真实验证工具参数、中英文、
文字保护和多轮修改。失败时显式报错、保留输入，不无声切换到其他理解模型。

生成选择从现有在售配置中筛选。顺序为：用户明确要求 → 附件及模型能力 →
已批准的套餐限制 → 默认方案 → 服务器核价。不能由 LLM 编造模型、API 参数或价格。
候选均不能满足时说明缺口并请用户调整，不静默删除素材、降规格或改需求。

| 场景 | 建议默认 |
| --- | --- |
| 普通图片/图片模板 | GPT-Image-2.5 Flare，1K；普通无数量要求 1 张，模板初次 4 张 |
| 选图继续编辑 | 优先原生成模型，保留明确要求；默认 1 张，模板锁方向 |
| 普通视频/选图生成视频 | Seedance 2.0 Mini，720P、5 秒、Sound On、每次 1 个视频 |
| 特殊需求 | 从现有七个图片模型、六个视频模型中选满足要求的候选，并重新展示方案 |

2026-09-14 用户确认默认有声及 PRODUCT 第 22 节比例/分辨率白名单同步到 Agent；
此为需求更新，尚未开发。Agent 不显示模型参数面板，继续通过自然语言选参；
支持声音的模型默认开启，用户明确要求无声时仅在实际通路支持关闭时执行，否则
说明限制并提供兼容方案。确认卡显示实际声音状态；旧报价不得隐藏改变为有声。
白名单同样约束 Agent 工具与服务端校验，不能通过自然语言请求绕过。
用户明确批准 MiniMax H3 的 720P 显示档位映射实际 Provider 768P；Agent 确认卡
显示 720P，实际调用仍传 768P，与直接创作一致，不增加单独的 768P 选项。

以上为稳定起点，不是质量排名。例如 1080P/长视频/首尾帧等需求按 PRODUCT 第 7 节
能力筛选；存在多个候选时优先满足要求且积分较低的方案，同价保持固定顺序，避免
相同需求无理由反复切换模型。用户可在对话里指定现有模型，但仍需通过能力与权益校验。
无比例要求时图片根据用途建议，缺少用途则 1:1；视频有主体图时优先适配图片，
无图且无用途时建议 16:9。默认值必须展示，用户可在确认前用自然语言修改。

现有平台配置举例：GPT-Image-2.5 Flare 1K 单图 2 积分，模板四图 8 积分；Seedance Mini
720P 5 秒按现有公式为 22 积分。开发时复用计价函数而非复制这几个数值。

附件区分两类能力：

- Agent 直接理解：首版文字、图片。当前 OpenRouter 模型列表明确为 text+image 输入；
  虽模型介绍讨论视频能力，不能因此宣称当前调用通路可理解视频或音频。
- 视频生成参考：可以将视频/音频作为现有支持模型的输入，但用户需说明其用途与
  要保留/修改的内容。Agent 不声称已经观看或听取，必要时请求关键帧图片或文字说明。

单文件与上传额度沿用既有规则。模型选择后核验参考类型、数量、时长、大小和权益；
不兼容附件保持可见，等待用户处理，不能偷偷丢弃。若用户需要直接分析完整视频/音频，
这是独立能力扩展，需另行验证通路、成本和范围。

## 5. 上下文与执行

持久化会话完整消息，但理解请求只装载当前任务需要的内容：模板及版本、已确认的
事实和必显文字、当前目标、所选输出与必要原始参考、未完成方案，以及最近消息。
旧对话可压缩成摘要；精确文案、价格、日期、品牌名不通过摘要覆盖原始值。用户的
显式修改更新事实版本；材料里的文字不自动升级成用户要求。

用户可通过“修改此前要求”发新消息修正，不重写已扣费任务或删除历史事实；首版
不做 ChatGPT 式历史消息分支。输出状态以生成服务为准，Agent 不能将预测或自评
当成完成、退款或质量通过。生成完成用确定性状态卡展示，不为每次轮询调用 LLM。

建议工具边界：读当前会话上下文/授权素材、列出有效媒体能力、整理方案与请求报价。
付费执行必须由服务端确认接口触发，不把可直接扣费的任意函数交给语言模型。
确认记录绑定账号、会话、方案 revision、输入资产、规格、报价版本和幂等键。
报价不因时间自动失效；点击 Generate 时重新校验价格、余额、素材与可用参数。需求、素材或
规格改变仍必须重新展示并确认。

模型调用、普通聊天和媒体执行分开记录。媒体提交预约、扣费、任务及引用采用现有
事务约束；不得只依靠 SDK 工具批准字段或 UI disabled 防止重复扣费。

## 6. 中断、删除与旧模板兼容

- 普通回复流式展示；刷新后从数据库恢复已保存消息和运行状态，不承诺逐 token
  无缝接续。回复中断显示可重试状态；不得自动重放媒体请求。
- 回复开始先登记消息 ID 和运行状态，分段保存服务端内容；完成、超时或中断落库。
  失去执行进程时以有时限的租约收敛到可重试状态，不能一直显示思考中。
- “停止回复”只停止当前理解/文本回复，不撤销已确认的媒体任务。退出页面也不取消媒体任务。
- 暂不引入 Redis 来恢复流；AI SDK 的完整可恢复流另需流存储设施，超出首版最小方案。
- 会话有未终结媒体、未结退款或保存/清理义务时暂不允许删除，并给出原因；
  正在文本回复时先停止再删除。等待完成后可删除，不新增隐藏后台会话模式。
- 会话删除后历史入口和消息不可访问，生成作品仍在 Assets；引用中的媒体不删除。
  仅作为会话附件且无其他引用的资产进入现有清理机制；失败清理保留可重试义务。
  删除账号仍按现有账号删除规则执行，不等同删除会话。
- 已提交旧模板任务继续原任务/退款路径，不迁移、不重放；旧历史在 Image/Assets
  继续可见。点击旧结果继续编辑，可创建新 Agent 会话并带入模板版本、已知事实与所选图。
- 新模板入口统一走 Agent。旧未提交草稿提供“继续旧草稿”提示，将可恢复内容带入
  新会话后重新确认，保留旧数据直到新会话保存成功，不自动批量迁移或再次提交。
  本地未同步的旧草稿只在原浏览器可恢复，不承诺跨设备找回。
- 新 Agent 输出首版显示于所属会话和 Assets，不混入普通 Image/Video 操作流；
  已有普通历史保持原样。以来源标识筛选，避免两个界面重复上报同一输出事件。

## 7. Analytics（四个新增事件已确认；模板兼容映射为工程草案）

保留 PRODUCT 第 12 节事件含义；生成仍是生成，发送聊天不算 generation_started。
已确认新增四项 Agent 事件：

| 事件 | 触发与去重 |
| --- | --- |
| agent_conversation_started | 首条用户消息持久化并创建会话后；同会话一次；打开空页不算 |
| agent_message_submitted | 服务端接受一条用户消息并预约执行后；同 message ID 一次；失败重试同消息不重复 |
| agent_quote_viewed | 当前有效报价卡至少 50% 进入视口；同 quote revision 在同浏览器会话内一次 |
| agent_limit_reached | 展示每日额度、短时频率或全站暂不可用提示；同请求和原因一次 |

建议调整模板事件映射：template_view 保持；template_click 改为卡片点击进入模板
会话，不在登录恢复时补记；template_input_submit 仅带模板的消息被服务端接受时计，
与 agent_message_submitted 并行但不相加作为提交总量。clarification_started 为每个
生成意图首次提出缺失问题；clarification_completed 为该意图首次形成可报价规格，
修改需求产生新 revision 才可再次记录；恢复页面不补记。普通闲聊不计澄清事件。
variant_selected 和 continued_edit 沿用所选方向/继续编辑语义，选图转视频不冒充图片编辑。

generation_started 在已确认任务组首次被服务端接受时记录；结果按输出的首次终态
记录；result_download_clicked 和 insufficient_credits_shown 继续现有语义。Agent
与普通工作台共用账号+输出 ID 的终态去重标识。仅浏览器观察到的活跃任务上报结果，
离线完成可能漏记，不宣称跨设备精确一次；账务和可靠成功率使用服务端任务记录。

GA4 仅传入口类型、模板 ID、媒体类型、模型标识、输出数、规格、积分和枚举原因等
允许字段；不传会话标题、Prompt、答案、素材 URL 或会话/用户/消息原始标识。
去重 ID 仅在应用内使用。Agent page_view 使用 `/agent` 或 `/agent/[id]` 模板路径，
清除含私有 ID 的 page_location、page_title 和 page_referrer；需核对自动采集配置。

- 技术实现：AI SDK 7.0.97 + OpenAI-compatible 3.0.47 + Zod 4.6.2；Qwen ID 不变，
  仅理解工具可提出问题或核价，模型不能调用扣费工具。真实供应商响应尚待授权验收。
- 路由：`/agent`、`/agent?template=<id>`、`/agent/<uuid>`；`/api/agent`
  负责账号校验、对话、确认、停止、人工重试、重命名与删除。空会话不写数据库。
- 数据：AgentConversation、AgentTurn、AgentUsage、AgentAttachment。User 行锁串行化
  同账号写操作；报价按 revision/时效/当前价格复核；任务 ID 与扣费同事务保存。
  新表启用 RLS，浏览器角色无表权限，只有既有服务端角色获得业务访问权限。
- 工程取值：普通图片未指定数量用 1 张/1K；模板默认 4 张，编辑 1 张；报价不设时间有效期。
  每分钟 6 次提交、账号同时 1 个理解回复；80 秒超时、100 秒运行租约，最多 3 步，
  每步最多 1,500 输出 tokens。所有历史原文参与上下文，不静默丢弃旧消息；字符总量
  超过 28,000 时保留消息并明确建议新会话。未实现自动摘要压缩。
- 回复文本每秒保存快照；页面在回复时 1.5 秒、媒体运行时 3 秒、空闲时 15 秒刷新。
  这不是 Redis/SSE 字节流恢复，断连恢复靠数据库消息状态；离开不会自动付费重试。
  收到错误、截断或未完整结束的模型响应不计成功回复；可用 token 用量保存到运行记录。

  熔断承诺。多模态 token 和失败调用实际成本需用 Provider 账单核对，不以缺失用量当零成本。

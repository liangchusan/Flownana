# GPT Image 2.6 与 Kling 4.0 接入验收

状态：本地完成，用户已于 2026-11-06 批准提交、推送及生产部署，发布中。范围及用户固定价格决定见 PRODUCT 6.4/7.3。
本记录仅覆盖这两个新增系列及 2.5 退役，不重新宣称其他模型上游合同已在本日核查。

## 官方证据与平台范围

- [GPT 模型页](https://kie.ai/gpt-image-2-6)：四个模式通过
  `/api/v1/jobs/createTask` 创建、`/api/v1/jobs/recordInfo` 轮询；新 ID 中有 `/`。
  Flare/Sunburst 均为文字/参考图、1K/2K/4K；编辑 `input_urls` 最多 16 项。
- 三份 GPT docs 直达页曾返回 404，模型页 API 标签中的内嵌 Reference 可以读取。
  已逐模式核对 ID、Prompt、比例、分辨率、参考数组、输出格式；
  [结构化快照](KIE-MODEL-CONTRACTS.json)保存具体嵌入页 URL。
  平台仍为 5000 字、20 MB、JPEG/PNG/WebP、七项比例、1–4 个 PNG 独立输出。
  上游的背景、GIF 帧及更多比例未开放；局部文档对 GIF 参数存在描述/枚举差异，
  不影响本次固定 PNG 请求，不将这些字段作为已验证的产品能力。
- [Kling 模型页](https://kie.ai/kling-4-0)及
  [Reference 接口](https://docs.kie.ai/market/kling/v4-reference-to-video)：
  `kling-4.0/reference-to-video`，文字、普通图片/视频参考，720p/1080p，整数 3–30 秒。
  平台最多 10 图、5 视频，10 MB/文件，仅 JPEG/PNG/WebP 与 MP4；
  视频每段 2–30 秒、合计≤30 秒。图片执行 300–8000px/边及比例 0.4–2.5，
  叠加已有 6400 万像素解码上限。不接入关键帧、主体、声音克隆或 Flash。
- Kling 普通图片不转换成首尾帧；图片和视频分别按添加顺序编号。
  原生声音不提供关闭选项；有视频参考时固定不保留源原声，不能把该字段当作静音。

## 价格与历史兼容

- GPT 上游当前按 Token 收费，实时模型页与 [Pricing 表](https://kie.ai/pricing)一致；
  搜索抓取中的 6/10/16 KIE 积分每张已过时。
  用户明确批准平台仍收每输出 1K/2K/4K：2/3/5 积分，参考图不另加用户费用，
  不事后追扣 Token 成本。此定价是用户决定，不是从固定上游单价换算得出的。
- Kling 独立 Pricing UI 搜索 `kling 4.0` 核对六条价格，Reference 两档均与模型页一致。
  无视频 720P/1080P：28.5/42.5 KIE 积分/输出秒；有视频：17/25.5 积分/计费秒。
  计费秒 = 输出 + max(已核实输入视频合计时长, 输出)，整次成本乘 0.2 后四舍五入。
- 前端、Agent 报价和服务端共用价格。视频时长由服务端重读真实字节；
  报价不符时扣费前拒绝。非法 `@` 引用、超限素材和不支持的无声请求同样扣费前拒绝。
- 2.5 不再提供新报价或新生成；历史元数据、作品、原 Provider ID 和已扣积分保持。
  接受过的 Agent/旧模板输出解析已保存的模型，不因默认值变化而切成 2.6。
  原已停用模板 HTTP 接口继续停用；内部模板默认改为 2.6 Sunburst，不恢复旧入口。
- 直接图片默认仍为 Nano Banana 2.1；Agent 图片默认 2.6 Flare。
  视频默认 Seedance 保持，Kling 在菜单末尾。数据库、套餐、GA4 合同未变。

## 实际验证

- 完整 `npm run test`：524 项，507 通过、17 项环境依赖跳过、0 失败。
  其中新增覆盖所有 Kling 时长/分辨率、输入视频计费分支、参考限制与非法引用、
  Agent 价格/退役校验、旧图片输出通路；现有图片路由逐模型成功/失败、存储与结算回归通过。
- `npx tsc --noEmit`、`npm run build`、`npm run design:check` 通过。
  `npm run lint` 为 0 错误、15 个既有警告；生产构建含既有 Stripe 只读校验，未发起收费。
- 本地生产构建启动时明确指向不可连接的本地数据库，清空 KIE/OpenRouter Key，
  关闭测试登录；未触碰业务库。真实 GET 视频目录返回六模型、56 个 Kling 规格，
  未登录图片/视频 POST 均返回应用层 401。
- 内置浏览器检查普通创作与 Agent 的同一参数面板：首次打开、关闭重开、刷新、
  选择模型/参数、Esc 和参数保留。发现长列表重开时选中项不可见，已修正为只滚动模型列表，
  不移动页面或右侧参数区域，并重新构建、浏览器回归。
- 实查视口：Home 图片 1440px、Home 视频 768px；Image 390/768/1440px；
  Video 390/1440px；Agent 390/768/1440px。检查过的 390/768px 文档宽度无横向溢出。
  普通 2.6 单张 2K=3、四张 4K=20；Kling 默认 720P/5s=29，1080P/30s=255。
- Agent 浏览器使用本地只读 fixture 代理提供模拟 Session/会话，不是真实账号登录。
  报价仍调用实际 `buildQuote`；验证 2.5 报价按钮禁用、切到 2.6 后重新报价、
  四张 4K=20、刷新恢复；Kling 两张参考显示 `@image_1`/`@image_2`，规格改变会重新报价。
  代理禁止真实生成、数据库写入及付款；并非完整真实 Agent/Provider 验收。
- 运行日志、源码文档快照、浏览器截图及只读 fixture 代理保存在本机忽略目录
  `output/model-integration-20261106/`，不随 Git 克隆恢复，不属于线上数据或远端备份。
